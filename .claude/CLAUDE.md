# Loge — project instructions

Native tvOS (Apple TV) Stremio client written in SwiftUI. Target: tvOS 18+, Swift 5 language mode, Xcode 27.

## Layout

- `project.yml` — XcodeGen spec (source of truth). Run `xcodegen generate` after adding/removing files; never hand-edit `Loge.xcodeproj`.
- `Sources/App` — app entry point and dependency wiring.
- `Sources/Design` — design tokens (`Theme.swift`) and reusable, pure SwiftUI components.
- `Sources/Assets.xcassets` — generated by `swift scripts/generate-brand-assets.swift` (ADR 0013); edit the script, not the PNGs.
- `Sources/Shared` + `Sources/Models` — compiled into both the app and the `TopShelf/` extension: keep them Foundation-only.
- `Sources/Models` — Codable models for the Stremio protocol and local library.
- `Sources/Services` — networking (`StremioService`), persistence (`LibraryStore`, `AddonStore`), pure logic (`StreamRanker`, `HTTPRequestParser`), local config web server.
- `Sources/Features/<Feature>` — one folder per screen: `View` + optional `ViewModel`.
- `Tests/LogeTests` — unit tests (Swift Testing).
- `docs/adr` — Architecture Decision Records.

## Conventions

- UI strings are **French**; code, comments, docs and ADRs are **English**.
- Views are pure: data loading and business rules live in view models (`@Observable @MainActor`) or services.
- Dependencies are injected through the SwiftUI environment from `LogeApp`; services sit behind protocols so tests can stub them.
- Use `Theme` tokens for colors, spacing, typography — no hardcoded values in features. Control scale goes through `Theme.Motion.scale(focused:pressed:)` so a click is visible on the focused element.
- Playback goes through libVLC (`VLCPlayerEngine`); AVPlayer cannot open the MKV/DTS/PGS files addons return. Diagnose playback issues from raw data (engine state, `ffprobe` on the stream URL), not from addon labels.
- Navigation is a custom icon rail (ADR 0010): the system sidebar cannot drop its backgrounds. The rail is gated (`railReady`/`railSuppressed` in RootView): enabled from the start it steals the initial focus while a page loads (ADR 0011).
- Profiles (ADR 0014): the library is per profile, stored in the App Group defaults. Migrations must COPY, never move or delete. Never install a build without the `application-groups` entitlement over the real app: its data then goes to an app-local file and the real store looks empty. This happened through a UI-test project that had an app target with the same bundle id and kept a stale copy in its build products (ADR 0016): a UI-test project must only contain the test bundle and launch the app by bundle identifier.
- Secrets (addon URLs embed debrid keys) go to the Keychain, never to `UserDefaults` or logs.

## Commands

```bash
./scripts/fetch-vlckit.sh   # once per clone: TVVLCKit into Vendor/ (git-ignored), see ADR 0007
xcodegen generate
xcodebuild -project Loge.xcodeproj -scheme Loge -destination "generic/platform=tvOS Simulator" build-for-testing
xcodebuild -project Loge.xcodeproj -scheme Loge -destination "id=<APPLE_TV_UDID>" -allowProvisioningUpdates test
```

No tvOS simulator runtime is installed on the main dev machine; tests run on the physical Apple TV.
